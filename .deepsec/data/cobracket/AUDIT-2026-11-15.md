## Accepted residuals (decisions, not oversights)

- Finding 9 is fixed by bounding, not by removing the flagged code
  shape: the suggestion view still materializes the table, by
  deliberate documented design (the unique index exposes only `find`;
  range scans proved unusable from module code under the test
  harness). What the fix removes is the abuse vector — the only
  minting path is now capped at 1,000 rows on both backends (#5/#7),
  so per-call work is bounded. The revalidation verdict is "fixed"
  on the vulnerability as written (unbounded cost via an inflatable
  table).
- The tarball verdicts (#12–#15) cover the download path: every
  driver now hashes the download against the one pinned SHA-256
  before extraction. Binaries supplied explicitly through
  `SPACETIME_BIN_DIR`, and caches populated before the fix, are
  operator-supplied inputs rather than downloads and are not
  re-hashed by the reuse path; clearing the local build dirs once is
  the one-time remedy.
- `ci.yml` still uses major-version action tags, unchanged by
  design: the audit judged it not a finding (PR-only, `contents:
  read`, no secrets).
- Discipline rows are still never deleted; with the 1,000-row cap on
  new-row creation (both backends) that is now a bounded permanent
  namespace rather than an unbounded one.
